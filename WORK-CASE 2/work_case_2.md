# Базові дії в Oracle VirtualBox

Нижче наведено опис основних операцій для налаштування та роботи з віртуальними машинами в середовищі Oracle VirtualBox.

## 1. Створення нової віртуальної машини
- Запустіть програму **VirtualBox**.
- Натисніть кнопку **«Створити»** (New) на головній панелі.
- Вкажіть **ім'я** віртуальної машини та оберіть **тип операційної системи** (наприклад, Windows, Linux).
- Задайте **обсяг оперативної пам'яті** (RAM), який буде виділено для гостьової ОС.
- Створіть **новий віртуальний жорсткий диск** (наприклад, у форматі VDI) та вкажіть його розмір.
  
  ![Створення нової машини](/WORK-CASE%202/images/photo_1_2026-09-24_16-46-14.jpg)

## 2. Вибір та додавання обладнання
- Виділіть створену машину та натисніть **«Налаштування»** (Settings).
- У розділі **«Система»** (System) -> вкладка *Процесор* задайте необхідну кількість процесорних ядер.
- У розділі **«Дисплей»** (Display) вкажіть потрібний обсяг відеопам'яті.
- У розділі **«Носії»** (Storage) додайте необхідні інсталяційні ISO-образи систем. Для цього оберіть іконку порожнього оптичного диска та вкажіть шлях до завантаженого ISO-файлу на вашому комп'ютері.

    ![Виділення обсягу пам'яті та кількість процесорних ядер](/WORK-CASE%202/images/photo_5_2026-09-24_16-46-14.jpg)

## 3. Налаштування мережі (та підключення до Wi-Fi)
VirtualBox надає гнучкі механізми віртуалізації мережевих адаптерів (NIC) для взаємодії гостьової операційної системи з локальними та глобальними мережами через фізичні інтерфейси робочої станції.

- Перейдіть у розділ **«Мережа»** (Network) у налаштуваннях віртуальної машини.
- Переконайтеся, що активовано пункт **«Увімкнути мережевий адаптер»** (за замовчуванням емулюється адаптер сімейства Intel PRO/1000).
- Оберіть необхідний режим трансляції пакетів:
  - **NAT (Network Address Translation):**
    - Встановлюється за замовчуванням. Гіпервізор ізолює гостьову ОС у внутрішній віртуальній підмережі (зазвичай `10.0.2.0/24`) та транслює вихідні TCP/UDP-пакети через активний стек хоста.
    - Доступ до Інтернету (включаючи хостове бездротове з'єднання Wi-Fi) надається автоматично та прозоро для віртуальної машини без потреби додаткової автентифікації у бездротовій мережі. Зворотний прямий доступ із зовнішньої мережі до ВМ заблокований, що забезпечує базовий рівень безпеки.
  - **Мережевий міст (Bridged Adapter):**
    - Віртуальний мережевий драйвер напряму взаємодіє з обраним фізичним адаптером хоста (Ethernet або Wi-Fi-картою) на канальному рівні (L2).
    - Віртуальна машина отримує власну унікальну MAC-адресу, відправляє DHCP-запит безпосередньо фізичному маршрутизатору (роутеру) і стає рівноправним вузлом домашньої або корпоративної локальної мережі з виділеною локальною IP-адресою.

  ![Налаштування Мережі](/WORK-CASE%202/images/photo_3_2026-09-24_16-46-14.jpg)

## 4. Робота із зовнішніми носіями (USB/Flash-пам'ять)
Для забезпечення прямого доступу гостьової ОС до фізичних USB-накопичувачів використовується механізм апаратного перехоплення (USB Pass-through).

- Підключіть фізичний USB-накопичувач (флеш-пам'ять) до відповідного порту робочої станції.
- У вікні налаштувань віртуальної машини відкрийте категорію **«USB»**.
- Активуйте чекбокс **«Увімкнути контролер USB»** та оберіть відповідну ревізію стандарту:
  - **USB 2.0 (EHCI)** або **USB 3.0 (xHCI)** — забезпечують високу швидкість передачі даних (потребують встановленого розширення Extension Pack).
- За допомогою кнопки додавання фільтра зі списку підключених периферійних пристроїв оберіть вашу флешку. Гіпервізор зчитає унікальні апаратні ідентифікатори:
  - `VendorID` (ідентифікатор виробника);
  - `ProductID` (ідентифікатор пристрою).
- **Принцип роботи:** При запуску віртуальної машини системний сервіс гіпервізора тимчасово перехоплює керування пристроєм у драйвера хостової операційної системи. Фізичний накопичувач автоматично монтується всередині гостьової системи як звичайний блочний пристрій і стає доступним для читання/запису.

# Встановлення GNU/Linux з графічною оболонкою (Ubuntu Desktop)

Нижче наведено покроковий процес встановлення операційної системи Ubuntu з графічним середовищем GNOME у VirtualBox.

## 1. Запуск інсталятора
- Оберіть створену віртуальну машину та натисніть кнопку **«Запустити»** (Start).
- У вікні вибору оптичного диска підтвердіть завантажений ISO-образ **Ubuntu Desktop**.
- У меню завантажувача GRUB виберіть пункт **«Try or Install Ubuntu»** та натисніть Enter.

## 2. Налаштування параметрів системи
- На стартовому вікні оберіть зручну **мову інсталяції** та натисніть кнопку **«Install Ubuntu»**.
- Оберіть необхідну **розкладку клавіатури**.
- Виберіть варіант встановлення **«Normal installation»** (встановлює браузер, стандартні графічні утиліти та мультимедіа).
- У меню типу розмітки оберіть **«Erase disk and install Ubuntu»** (автоматична розмітка віртуального диска) та підтвердіть запис змін кнопкою **«Install Now»**.

## 3. Створення користувача та запуск
- Виберіть свій **часовий пояс** на інтерактивній карті.
- Вкажіть **ім'я користувача**, назву комп'ютера та встановіть пароль для входу в систему.
- Дочекайтеся закінчення копіювання системних файлів і натисніть кнопку **«Restart Now»**.
- Після перезавантаження введіть пароль облікового запису та увійдіть до графічного середовища GNOME.

## 1. Встановлення Debian у мінімальній конфігурації

Створюємо другу віртуальну машину, підключаємо ISO-образ Debian і запускаємо встановлення в текстовому режимі. На етапі Software selection знімаємо позначки з усіх графічних середовищ і залишаємо лише «standard system utilities». Після завершення встановлення перезавантажуємо систему.

![Рис. 1 — Вибір програмного забезпечення без графічного середовища](/WORK-CASE%202/images/photo_2026-09-24_18-41-35.jpg)

Входимо в консоль і перевіряємо, що графічної оболонки немає:

```bash
cat /etc/os-release
systemctl get-default
```

Команда `systemctl get-default` повертає `multi-user.target`, тобто система працює без графічного інтерфейсу.

![Рис. 2 — Мінімальна система Debian у текстовому режимі](/WORK-CASE%202/images/photo_2026-09-24_18-42-47.jpg)

## 2. Встановлення GNOME

Оновлюємо список пакетів і встановлюємо GNOME:

```bash
sudo apt update
sudo apt install gnome -y
```

Вмикаємо графічний режим за замовчуванням і перезавантажуємо систему:

```bash
sudo systemctl set-default graphical.target
sudo reboot
```

Після перезавантаження входимо через екран входу GDM.



Відкриваємо термінал і виконуємо команду, яка показує оболонку та використання пам'яті:

```bash
sudo apt install fastfetch -y
fastfetch
```



## 3. Встановлюємо Xfce:

```bash
sudo apt install xfce4 xfce4-goodies -y
```

Виходимо із сесії, на екрані входу натискаємо значок шестерні, обираємо сесію Xfce та входимо в систему.



У терміналі знову виконуємо команду:

```bash
fastfetch
```

## 4. Порівняння Xfce з GNOME

Споживання пам'яті в GNOME становить приблизно *(значення з Рис. 4)*, у Xfce — *(значення з Рис. 6)*. Xfce легша, тому краще підходить для слабких комп'ютерів і віртуальних машин.

GNOME має мінімалістичний інтерфейс з оглядом Activities і без класичного меню програм, налаштування зовнішнього вигляду в ньому обмежені та розширюються через GNOME Extensions. Xfce має традиційний інтерфейс із панеллю та меню програм і дозволяє гнучко змінювати панелі, теми та поведінку вікон вбудованими засобами.

У GNOME за замовчуванням використовуються Nautilus і сесія Wayland, у Xfce — Thunar і X11.

Отже, GNOME дає цілісний сучасний інтерфейс, але потребує більше ресурсів, а Xfce швидша й краще налаштовується під потреби користувача.
