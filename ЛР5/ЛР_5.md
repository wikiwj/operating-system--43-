## 2. Відповіді на питання для попередньої підготовки

### 2.1. Порівняння файлових структур Windows-подібної та Linux-подібної систем

| Критерій | Windows | Linux |
| --- | --- | --- |
| Вершина ієрархії | «Мій комп'ютер» (My Computer / This PC), під яким відображаються пристрої | Єдиний кореневий каталог `/` (root) |
| Пристрої зберігання | Кожному розділу чи пристрою призначається літера диска: `C:`, `D:` тощо | Дисків-літер немає: кожен пристрій підключається (монтується) до певного каталогу, наприклад `/media`, `/mnt` |
| Роздільник у шляху | Зворотна коса риска `\` (`C:\Users\vboxuser`) | Пряма коса риска `/` (`/home/vboxuser`) |
| Регістр в іменах | Зазвичай не враховується | Враховується: `File` і `file` - різні файли |
| Домашній каталог | `C:\Users\<ім'я>` | `/home/<ім'я>` |
| Структура | Кілька незалежних дерев (по одному на диск) | Єдине віртуальне дерево каталогів |
| Принцип | Файли, папки та пристрої розрізняються | «Все є файл», навіть пристрої (`/dev`) |

Отже, головна відмінність: у Windows файлова система складається з кількох дерев за літерами дисків, а в Linux - з одного дерева з єдиним коренем `/`, у яке «вбудовуються» усі пристрої.

### 2.2. Поняття FHS

**FHS (Filesystem Hierarchy Standard)** - це стандарт, що визначає назви основних каталогів файлової системи Linux-подібних систем і їх призначення. Завдяки йому каталоги з однаковими іменами виконують однакові функції в різних дистрибутивах.

Приклади: `/bin` - базові програми, `/etc` - конфігураційні файли, `/home` - домашні каталоги користувачів, `/var` - файли, що часто змінюються (логи), `/tmp` - тимчасові файли, `/dev` - файли пристроїв, `/usr` - основна частина програм і даних користувача.

Використання стандарту дає користувачу й адміністратору можливість швидко знаходити потрібні файли в будь-якому FHS-сумісному дистрибутиві, а розробникам програмного забезпечення - розраховувати на передбачувану структуру системи.

### 2.3. Основні команди для роботи з файлами та каталогами

| Дія | Команда | Приклад |
| --- | --- | --- |
| Створення порожнього файлу | `touch` | `touch file.txt` |
| Створення каталогу | `mkdir` | `mkdir mydir` |
| Копіювання | `cp` | `cp file.txt copy.txt`, `cp -r dir1 dir2` |
| Переміщення / перейменування | `mv` | `mv file.txt dir/`, `mv old.txt new.txt` |
| Видалення файлу | `rm` | `rm file.txt` |
| Видалення каталогу | `rmdir` (порожній), `rm -r` (з вмістом) | `rmdir mydir`, `rm -r mydir` |
| Перегляд вмісту каталогу | `ls` | `ls -l` |
| Перегляд вмісту файлу | `cat` | `cat file.txt` |

# Єршов Олексій:
## 4. Відповіді на контрольні запитання

### 4.1. Як переглянути шлях до домашньої директорії користувача за допомогою команди echo?

Є два способи.

**Спосіб 1 - за допомогою змінної `$HOME`:**

```bash
vboxuser@ubuntu:~$ echo $HOME
/home/vboxuser
```

**Спосіб 2 - за допомогою символу `~`:**

```bash
vboxuser@ubuntu:~$ echo ~
/home/vboxuser
```

**Пояснення:** команда `echo` виводить текст на екран. Змінна `$HOME` і символ `~` вказують на домашню директорію користувача. Тому обидві команди показують однаковий шлях.

### 4.2. Чи можна переглянути вміст кореневого каталогу, перебуваючи у домашньому каталозі, без переходу в кореневий каталог?

Так, для цього можна використати команду `ls /`. Вона покаже вміст кореневого каталогу, але поточна директорія не зміниться.

```bash
vboxuser@ubuntu:~$ pwd
/home/vboxuser

vboxuser@ubuntu:~$ ls /
bin  boot  dev  etc  home  lib  media  mnt  opt  proc  root  run  sbin  srv  sys  tmp  usr  var

vboxuser@ubuntu:~$ pwd
/home/vboxuser
```

**Пояснення:** символ `/` позначає кореневий каталог Linux. Команда `ls /` показує його вміст, а `pwd` показує поточну директорію. Як видно з прикладу, ми залишилися в `/home/vboxuser`. Так само можна переглянути інші каталоги, наприклад за допомогою команд `ls /etc` або `ls ../..`.

### 4.3. Як в терміналі додати інформацію в порожній файл?

Для цього можна використати команду `echo` та символ `>`, який записує текст у файл.

```bash
vboxuser@ubuntu:~$ touch file.txt
vboxuser@ubuntu:~$ echo "Hello, my name is Oleksii" > file.txt
vboxuser@ubuntu:~$ cat file.txt
Hello, my name is Oleksii
```

Існують й інші способи роботи з файлами:

| Спосіб | Що робить |
| --- | --- |
| `echo "текст" > file.txt` | Записує текст у файл і видаляє попередній вміст, якщо він був |
| `echo "текст" >> file.txt` | Додає текст у кінець файлу, не видаляючи старий вміст |
| `cat > file.txt` | Дозволяє вводити текст із клавіатури. Для завершення потрібно натиснути `Ctrl+D` |
| `nano file.txt` | Відкриває файл у текстовому редакторі. Зберегти зміни можна через `Ctrl+O`, а вийти - через `Ctrl+X` |

**Пояснення:** команду `touch` не обов'язково використовувати перед записом. Якщо файлу ще немає, команда з `>` створить його автоматично.

### 4.4. Як скопіювати та видалити існуючий каталог? Чи буде відмінність у командах, якщо каталог не порожній?

**Копіювання каталогу**

Для копіювання каталогу використовується команда `cp` з ключем `-r`.

```bash
cp -r dir1 dir2
```

Ключ `-r` дозволяє скопіювати каталог разом з усіма файлами та підкаталогами. Він потрібен навіть тоді, коли каталог порожній. Для перегляду виконаних дій можна додати ключ `-v`.

**Видалення каталогу**

Команда залежить від того, чи є в каталозі файли.

| Ситуація | Команда | Пояснення |
| --- | --- | --- |
| Каталог порожній | `rmdir dir1` | Видаляє порожній каталог |
| Каталог порожній або містить файли | `rm -r dir1` | Видаляє каталог разом із його вмістом |

Якщо спробувати видалити непорожній каталог командою `rmdir`, з'явиться повідомлення про помилку (`Directory not empty`).

Команда `rm` без ключа `-r` не видаляє каталоги. Тому для видалення каталогу з файлами використовують `rm -r`.

**Важливо:** команда `rm -r` може видалити всі файли без можливості простого відновлення. Щоб система запитувала підтвердження, можна використати команду `rm -ri dir1`.

### 4.5. У якому з прикладів відбувається переміщення, перейменування або обидві дії одночасно?

У першій команді після `comp.png` є зайва крапка. Імовірно, це помилка в умові, тому розглянемо команди без неї.

| Команда | Що відбувається | Пояснення |
| --- | --- | --- |
| `mv /work/tech/comp.png /Desktop` | Переміщення | Файл переноситься в каталог `/Desktop` зі старою назвою |
| `mv /work/tech/comp.png /work/tech/my_car.png` | Перейменування | Файл залишається в тому самому каталозі, але отримує нову назву |
| `mv /work/tech/comp.png /Desktop/computer.png` | Переміщення та перейменування | Файл переноситься в інший каталог і змінює назву |

**Пояснення:** команда `mv` використовується для переміщення та перейменування файлів. Якщо змінюється тільки каталог, відбувається переміщення. Якщо змінюється тільки назва - перейменування. Якщо змінюються і каталог, і назва, відбуваються обидві дії.
